Where it runs

Analysis preset

A preset is a named set of typed questions. Results are cached per preset, so switching never reuses one preset's answers for another. Default is the original six dimensions and stays user editable below.

Articles

When a post links out, x-scanner offers an Analyze article action. Nothing is fetched or billed until you click it. Article access is a separate, optional permission you grant here.

Dimensions

Each dimension is one typed question. All of them ride in the same request. A flag shows only when the answer crosses its threshold. Thresholds, labels, direction and color are display policy and never re-bill a post. Editing a question or the model does.
